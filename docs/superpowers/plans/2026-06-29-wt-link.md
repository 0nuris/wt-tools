# wt-link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `bin/wt-link`, a script that symlinks shareable gitignored artifacts (node_modules, .env, config) from a repo's main checkout into a linked worktree, with an idempotent repair path and human-run escape hatches for blocked operations.

**Architecture:** A single bash script resolves the target worktree and its main checkout (via `git worktree list --porcelain`), auto-detects gitignored root entries in main (minus a build/cache denylist), and symlinks each into the worktree — skipping correct links, repairing broken ones, and reporting real-file conflicts with an emitted `! rm … && wt-link` command. It never installs or chmods; blocked needs are surfaced as `!`-prefixed commands. It's wired into the `multi-repo-dispatch` skill and runnable standalone.

**Tech Stack:** bash 3.2+, git, bats-core (tests). No jq dependency.

## Global Constraints

- **bash 3.2 compatible** — macOS default. Under `set -euo pipefail`, expanding an empty array as `"${arr[@]}"` raises "unbound variable". Always use the `"${arr[@]+"${arr[@]}"}"` guard or gate iteration on `(( ${#arr[@]} ))`.
- **`set -euo pipefail`** at the top of the script (matches `wt-clean`/`wt-audit`).
- **Invoked via `bash …/wt-link`** — never relies on its own exec bit; needs no chmod.
- **Respects the user's permission denies by design** — the script MUST NOT run `npm/pnpm/yarn install`, `chmod`, or `rm -rf` of a real dir itself. For those it emits a `!`-prefixed human command. (It may `rm` its own symlinks — that's not `rm -rf`.)
- **Config precedence** mirrors `wt-audit`: global `${WT_TOOLS_CONFIG:-$HOME/.config/wt-tools/wt-tools.conf}` < repo-shared `.wt-tools.conf` < repo-personal `.wt-tools.local.conf` (the last two sourced from the **main checkout**). Pre-set env vars win over the global default.
- **Exit codes:** `0` reconciled/nothing pending; `1` human action pending (conflict or absent-in-main install); `2` usage / not a worktree / target is main.
- **Tests** set `WT_TOOLS_CONFIG` to an empty file (fixture) and pass knobs via env, exactly like `audit.bats`.
- Spec: `docs/superpowers/specs/2026-06-29-wt-link-worktree-artifact-linking-design.md`.

# Add gitignore patterns to a repo's main checkout (uncommitted is fine —
# git honors the working-tree .gitignore).
#   wt_ignore REPO PATTERN...
wt_ignore() {
  local repo="$1"; shift
  printf '%s\n' "$@" >> "$WT_ROOT/$repo/.gitignore"
}

# Create a gitignored artifact in a repo's main checkout.
#   wt_make_artifact REPO REL [CONTENT]
# Trailing slash on REL => a directory containing a `marker` file.
wt_make_artifact() {
  local repo="$1" rel="$2" content="${3:-x}" base
  base="$WT_ROOT/$repo"
  if [[ "$rel" == */ ]]; then
    mkdir -p "$base/${rel%/}"
    printf '%s\n' "$content" > "$base/${rel%/}/marker"
  else
    mkdir -p "$(dirname "$base/$rel")"
    printf '%s\n' "$content" > "$base/$rel"
  fi
}
```

- [ ] **Step 4: Create the skeleton script**

Create `bin/wt-link`:

```bash
#!/usr/bin/env bash
# wt-link — symlink shareable gitignored artifacts from a repo's main checkout
#           into a linked worktree (node_modules, .env, config, ...).
#
# Idempotent: re-running reconciles and repairs. Never clobbers real files;
# emits human-run commands for blocked ops (install, rm -rf of a real dir).
#
# Usage:
#   wt-link [WORKTREE_PATH] [--dry-run] [--quiet] [-h|--help]
#
# Exit: 0 reconciled; 1 human action pending; 2 usage / not a worktree.

set -euo pipefail

WT_TOOLS_CONFIG="${WT_TOOLS_CONFIG:-$HOME/.config/wt-tools/wt-tools.conf}"
# shellcheck source=/dev/null
[[ -f "$WT_TOOLS_CONFIG" ]] && . "$WT_TOOLS_CONFIG"

# ---- flag parsing --------------------------------------------------------
DRY_RUN=0
QUIET=0
TARGET=""
while [[ $# -gt 0 ]]; do
  case "$1" in
    --dry-run) DRY_RUN=1; shift ;;
    --quiet)   QUIET=1; shift ;;
    --help|-h) sed -n '2,14p' "$0" | sed 's/^# \{0,1\}//'; exit 0 ;;
    -*) echo "wt-link: unknown flag: $1" >&2; exit 2 ;;
    *)
      if [[ -z "$TARGET" ]]; then TARGET="$1"; shift
      else echo "wt-link: unexpected argument: $1" >&2; exit 2; fi ;;
  esac
done
TARGET="${TARGET:-$PWD}"

# ---- resolve worktree + main checkout ------------------------------------
if ! git -C "$TARGET" rev-parse --is-inside-work-tree >/dev/null 2>&1; then
  echo "wt-link: $TARGET is not inside a git repository." >&2
  exit 2
fi
WT_DIR="$(git -C "$TARGET" rev-parse --show-toplevel)"
MAIN_DIR="$(git -C "$TARGET" worktree list --porcelain \
            | awk '/^worktree /{print substr($0,10); exit}')"
if [[ -z "$MAIN_DIR" || ! -d "$MAIN_DIR" ]]; then
  echo "wt-link: could not locate the main checkout for $WT_DIR." >&2
  exit 2
fi
if [[ "$WT_DIR" == "$MAIN_DIR" ]]; then
  echo "wt-link: $WT_DIR is the main checkout — it's the source, nothing to link." >&2
  echo "         Run wt-link from inside a linked worktree." >&2
  exit 2
fi

echo "wt-link: worktree=$WT_DIR main=$MAIN_DIR"
```

In `bin/wt-link`, **delete** the `echo "wt-link: worktree=..."` line and append:

```bash
# ---- per-repo config + knob defaults -------------------------------------
# shellcheck source=/dev/null
[[ -f "$MAIN_DIR/.wt-tools.conf" ]] && . "$MAIN_DIR/.wt-tools.conf"
# shellcheck source=/dev/null
[[ -f "$MAIN_DIR/.wt-tools.local.conf" ]] && . "$MAIN_DIR/.wt-tools.local.conf"
: "${WT_LINK_AUTO:=true}"
: "${WT_LINK_PATHS:=}"
: "${WT_LINK_EXCLUDE:=}"

# ---- denylist ------------------------------------------------------------
BUILTIN_DENY=(.next .nuxt .svelte-kit dist build out .output coverage .turbo \
              .cache .parcel-cache .vite .pytest_cache __pycache__ '*.log' \
              .DS_Store Thumbs.db)
USER_DENY=()
# shellcheck disable=SC2206
[[ -n "$WT_LINK_EXCLUDE" ]] && USER_DENY=( $WT_LINK_EXCLUDE )
DENY=( "${BUILTIN_DENY[@]}" "${USER_DENY[@]+"${USER_DENY[@]}"}" )

is_denied() {
  local name="$1" pat
  for pat in "${DENY[@]}"; do
    # shellcheck disable=SC2053
    [[ "$name" == $pat ]] && return 0
  done
  return 1
}

# ---- build candidate set -------------------------------------------------
CANDIDATES=()
add_candidate() {
  local c="$1" e
  if (( ${#CANDIDATES[@]} )); then
    for e in "${CANDIDATES[@]}"; do [[ "$e" == "$c" ]] && return 0; done
  fi
  CANDIDATES+=("$c")
}

if [[ "$WT_LINK_AUTO" == "true" ]]; then
  while IFS= read -r entry; do
    [[ -z "$entry" ]] && continue
    entry="${entry%/}"
    [[ "$entry" == */* ]] && continue        # root-level only
    is_denied "$entry" && continue
    add_candidate "$entry"
  done < <(git -C "$MAIN_DIR" ls-files --others --ignored --exclude-standard --directory)
fi

# shellcheck disable=SC2206
[[ -n "$WT_LINK_PATHS" ]] && for entry in $WT_LINK_PATHS; do add_candidate "$entry"; done

# ---- reconcile -----------------------------------------------------------
created=0; repaired=0; ok=0; conflicts=0; pending=0
INFO=(); PROBLEM=()
note_info()    { INFO+=("$1"); }
note_problem() { PROBLEM+=("$1"); }

link_one() {
  local entry="$1" src="$MAIN_DIR/$1" dst="$WT_DIR/$1"

  if [[ -L "$dst" ]]; then
    local cur; cur="$(readlink "$dst")"
    if [[ "$cur" == "$src" ]]; then ok=$((ok+1)); return; fi
    if (( DRY_RUN )); then note_info "would repair: $dst -> $src (was $cur)"
    else rm "$dst"; mkdir -p "$(dirname "$dst")"; ln -s "$src" "$dst"
         note_info "repaired: $dst -> $src"; fi
    repaired=$((repaired+1)); return
  fi

  if [[ -e "$dst" ]]; then
    conflicts=$((conflicts+1))
    if [[ -d "$dst" ]]; then
      note_problem "conflict: $dst is a real dir, not a link to main — left as-is."
      note_problem "  replace it with the shared copy from main:"
      note_problem "    ! rm -rf \"$dst\" && wt-link \"$WT_DIR\""
    else
      note_problem "conflict: $dst is a real file, not a link to main — left as-is."
      note_problem "  replace it with the shared copy from main:"
      note_problem "    ! rm -f \"$dst\" && wt-link \"$WT_DIR\""
    fi
    return
  fi

  if (( DRY_RUN )); then note_info "would link: $dst -> $src"
  else mkdir -p "$(dirname "$dst")"; ln -s "$src" "$dst"
       note_info "linked: $dst -> $src"; fi
  created=$((created+1))
}

if (( ${#CANDIDATES[@]} )); then
  for entry in "${CANDIDATES[@]}"; do link_one "$entry"; done
fi

# ---- output --------------------------------------------------------------
if (( ${#PROBLEM[@]} )); then printf '%s\n' "${PROBLEM[@]}" >&2; fi
if (( ! QUIET )) && (( ${#INFO[@]} )); then printf '%s\n' "${INFO[@]}"; fi
(( QUIET )) || echo "wt-link: created $created, repaired $repaired, ok $ok, conflicts $conflicts, pending $pending"

(( conflicts + pending > 0 )) && exit 1 || exit 0
```

Note: this version classifies a candidate whose `src` is absent in main as a normal "create" with a dangling link — that is corrected in Task 5. For Task 2's tests, all sources exist in main.

## Linking shared artifacts into worktrees (`wt-link`)

A new worktree starts without anything gitignored — `node_modules`, `.env`,
config. `wt-link` symlinks those from the repo's **main checkout** into the
worktree, so agents don't run `npm install` (which is large, slow, and often
sandbox-blocked).

```bash
wt-link                 # reconcile the current worktree (default: cwd)
wt-link /path/to/wt     # a specific worktree
wt-link --dry-run       # report desired-vs-actual, change nothing
```

- **Auto-detect** links gitignored root entries present in main, minus a
  build/cache/log denylist (`.next`, `dist`, `coverage`, `*.log`, …). Tune via
  `WT_LINK_AUTO`, `WT_LINK_PATHS`, `WT_LINK_EXCLUDE` in `wt-tools.conf`.
- **Idempotent** — re-running is the repair path. It creates missing links,
  repairs dangling/wrong-target ones, and never clobbers a real file you put
  there (it reports the conflict and prints `! rm … && wt-link` so you decide).
- **Never installs or chmods.** If main has no `node_modules`, it prints the
  exact `! (cd <main> && npm install)` for you to run once; every later
  worktree then benefits. Exit code is `1` while any human step is pending.
```
